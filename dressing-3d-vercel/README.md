# Habillage dressing 3D

Site statique : aucune étape de build.

- Test local : `npx serve .` (ou ouvrir index.html)
- Vercel : `vercel` dans ce dossier, ou import du dépôt avec le preset « Other » (dossier racine = ce dossier, pas de commande de build).

Three.js r128 et OrbitControls sont fournis dans `vendor/` (licence MIT).
